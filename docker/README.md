# Docker

Ce dossier contiendra la configuration Docker du projet Auto Hall Landing Page Builder.

La configuration Docker complète sera ajoutée dans une étape séparée afin de ne pas mélanger :
- la création du squelette applicatif ;
- la configuration de l’infrastructure ;
- la connexion à PostgreSQL ;
- l’intégration Prisma.

Services prévus :
- frontend React/Vite ;
- backend NestJS ;
- PostgreSQL ;
- pgAdmin optionnel pour le développement local.
